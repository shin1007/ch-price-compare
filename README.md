# ch-price-compare
手動での価格比較を支援する Chrome 拡張です。

## 使い方
1. Chrome の拡張機能ページ（`chrome://extensions`）を開く
2. デベロッパーモードを有効化
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択
4. 拡張アイコン（または Alt+Shift+P）でサイドパネルを開く（画面内のボタンでポップアップ表示にも切り替え可能）

## 機能
- 横に広い表形式の入力グリッド
- 入力行
  - 1箱の入り数（個）
  - 購入箱数（箱）
  - 商品価格（円）
  - 送料（円）
  - リンク
- 自動計算行
  - 支払総額（円）
  - 最安マーク（★）
  - 1個あたり単価（円）
- 行列入れ替えボタン
- クリアボタン
- 初期状態は候補を縦に比較する転置表示
- 候補を追加するボタン
- ブラウザの言語設定に応じた主要10言語以上の表示（アラビア語は右から左のレイアウト、拡張機能名・説明は `_locales/` で多言語化）
- 入力はセッション保存（ブラウザ再起動でクリア）

計算式: 支払総額（円） =（商品価格（円） × 購入箱数（箱））+ 送料（円） / 1個あたり単価（円） = 支払総額（円） ÷（1箱の入り数（個） × 購入箱数（箱））
