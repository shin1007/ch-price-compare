# ch-price-compare
手動での価格比較を支援する Chrome 拡張です。

## 使い方
1. Chrome の拡張機能ページ（`chrome://extensions`）を開く
2. デベロッパーモードを有効化
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択
4. 拡張アイコンからポップアップを開く

## 機能
- 横に広い表形式の入力グリッド
- 入力行
  - 1箱の入り数（個）
  - 購入箱数（箱）
  - 合計価格（円）
- 自動計算行
  - 最安マーク（★）
  - 1個あたり単価（円）
- クリアボタン
- 入力はセッション保存（ブラウザ再起動でクリア）
